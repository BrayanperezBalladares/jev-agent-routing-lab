# Generated Results

This directory contains local JSON outputs generated by the
benchmark, consistency, comparator, and diagnostic experiment
scripts.

Raw result JSON files are intentionally excluded from Git
because they are generated artifacts and may contain large
amounts of repeated experimental data.

---

## Why results are not committed

The repository separates:

```text
cases/
```

which contains the experimental inputs,

from:

```text
results/
```

which contains generated outputs.

The datasets and experiment runners are version controlled.

Raw result files can be regenerated by rerunning the
corresponding experiment.

---

## Example

Run the V8 implementation-explicitness experiment:

```bash
pnpm exec tsx src/v8-implementation-explicitness.ts
```

A timestamped JSON result will be written to this directory.

Example:

```text
results/
└── jev-v8-implementation-explicitness-<timestamp>.json
```

## Reproducibility note

External model and provider behavior may change over time.

A newly generated result may therefore differ from the
historical measurements documented in this repository because
of changes in:

- hosted model behavior
- provider infrastructure
- gateway routing
- rate limits
- network conditions
- endpoint availability

Historical summaries represent the observations obtained
during the original experimental runs.

---

## Security

Generated result files should never contain API keys.

Environment credentials are stored separately in:

```text
.env
```

which is excluded from Git.

Never place secrets directly inside experiment source files,
datasets, or generated documentation.
